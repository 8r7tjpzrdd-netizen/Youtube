# Транскрибация видео с YouTube

Инструмент вытаскивает текст из видео на YouTube: сначала пробует готовые
субтитры (ручные, затем автоматические), а если их нет — распознаёт звук
локально через `faster-whisper`.

## Установка

```bash
pip install -U yt-dlp
# только для распознавания звука (когда субтитров нет):
pip install faster-whisper           # плюс системный ffmpeg
```

## Запуск

```bash
python3 tools/yt_transcribe.py https://youtu.be/VIDEO_ID -l ru
python3 tools/yt_transcribe.py VIDEO_ID -l en -o transcripts
python3 tools/yt_transcribe.py VIDEO_ID --whisper   # игнорировать субтитры
```

Результат складывается в `transcripts/<video_id>/`:

| Файл | Что внутри |
|---|---|
| `transcript_raw.txt` | сплошной текст без таймкодов |
| `transcript_timed.txt` | текст блоками по 30 секунд с таймкодами |
| `subs.<lang>.json3` | исходные субтитры YouTube |

## Обход блокировок YouTube

YouTube отдаёт `HTTP 429` и «Sign in to confirm you're not a bot» на клиент
`web`. Скрипт перебирает клиентов плеера в порядке `ios → web_embedded →
android_vr → tv → mweb → web`; на практике субтитры отдаёт `ios`. Если ни один
клиент не проходит, варианты по возрастанию сложности:

1. подождать и повторить — лимит 429 временный;
2. передать cookies: `yt-dlp --cookies cookies.txt`;
3. поставить JS-рантайм (`deno`) — нужен для решения n-challenge при скачивании
   самих видеопотоков, для субтитров не обязателен.

## Точность

Автоматические субтитры YouTube — это распознавание речи, а не расшифровка
человеком. Имена собственные, термины и иноязычные вставки (санскрит, латынь,
жаргон) искажаются. Перед использованием текста как источника фактов сверяйте
спорные места со звуком.
