# Транскрибация видео с YouTube

Два способа получить текст:

| Режим | Что делает | Скорость | Качество |
|---|---|---|---|
| `--mode subs` | забирает субтитры YouTube | секунды | среднее, чужое ASR |
| `--mode whisper` | распознаёт звук моделью Whisper | ~0.5–1× длительности на 4 CPU | заметно выше |

## Установка

```bash
pip install -U yt-dlp yt-dlp-ejs faster-whisper
apt-get install -y ffmpeg
# Node >= 22 нужен yt-dlp для JS-челленджей YouTube
```

## Запуск

```bash
# субтитры
python3 tools/yt_transcribe.py https://youtu.be/VIDEO_ID --mode subs -l ru

# распознавание звука (аудио качается автоматически)
python3 tools/yt_transcribe.py https://youtu.be/VIDEO_ID --mode whisper --cookies cookies.txt

# распознавание уже скачанного файла
python3 tools/yt_transcribe.py lecture.m4a --mode whisper -l ru

# сложный фрагмент: замедлить до 0.75 и распознать только его
python3 tools/yt_transcribe.py lecture.m4a --mode whisper --speed 0.75 --from 21:00 --to 26:00
```

Результат в `transcripts/<имя>/`: `transcript_raw.txt` (сплошной текст),
`transcript_timed.txt` (блоки по 30 секунд), `transcript.srt` (субтитры).
Таймкоды при замедлении пересчитываются обратно к исходному темпу.

## Бот-проверка YouTube

Субтитры отдаёт клиент `ios`, а вот медиапотоки с IP дата-центра YouTube
закрывает: `HTTP 429` и `Sign in to confirm you're not a bot`. Перебор клиентов
плеера, JS-рантайм и генератор PO-токена (bgutil) проблему не решают — нужен
один из вариантов:

1. **cookies** — экспортировать `cookies.txt` из браузера, где выполнен вход в
   YouTube, и передать `--cookies cookies.txt`;
2. **скачать аудио на своей машине** (`yt-dlp -f bestaudio -o audio.m4a URL`) и
   отдать скрипту локальный файл — режим `--mode whisper` работает с ним без
   всякой сети.

## Оговорки о точности

- Автоматические субтитры YouTube — распознавание речи, а не расшифровка
  человеком. Имена, термины и иноязычные вставки искажаются.
- Whisper обучен на обычной речи. Пение, распевы и мантры на санскрите он либо
  пропускает, либо галлюцинирует; замедление звука помогает при быстрой
  разговорной речи, но незнакомый модели язык оно не чинит.
- Для канонических текстов (мантры, молитвы, стихи) надёжнее подставить
  выверенный источник, а не результат ASR.
